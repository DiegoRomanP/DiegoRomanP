## Proyectos destacados

- **[LexiTrace — evidencia documental con RAG](https://github.com/DiegoRomanP/lexitrace-legal-evidence-rag):** MVP local de investigación documental sobre PDFs seleccionados, con citas al documento, página y fragmento. No ofrece asesoría legal. **Stack:** FastAPI, React, TypeScript, SQLite y Qdrant.
- **[StudyAI](https://github.com/DiegoRomanP/StudyAI):** crea planes de estudio a partir de documentos y metas, con sesiones, materiales, cuestionarios y repaso espaciado SM-2. El LLM simulado está activo por defecto; el RAG semántico es opcional. **Stack:** FastAPI, React y TypeScript.
- **[Context IA Obsidian](https://github.com/DiegoRomanP/context-ia-obsidian):** plugin con acciones de IA para resumir o explicar notas, investigar con fuentes y generar imágenes. [Release v0.1.0](https://github.com/DiegoRomanP/context-ia-obsidian/releases/tag/v0.1.0). **Stack:** TypeScript.
- **[Give me some Credit](https://github.com/DiegoRomanP/Give-me-some-Credit):** experimento de predicción crediticia con XGBoost que compara métodos de balanceo. **Stack:** FastAPI, Streamlit y Docker.
